# 🪭 Enclosure — Fanora

## Konsep Desain

Casing berbentuk **kipas lipat setengah terbuka**, dengan 8 tombol tersusun
sepanjang busur 160°. Centerpiece berbentuk batu giok bulat yang menjadi
rumah bagi sensor PIR dan DHT22.

## Dimensi

| Parameter | Nilai |
|---|---|
| Lebar total | 180 mm |
| Tinggi total | 120 mm |
| Tebal body | 22 mm |
| Radius busur tombol | 70 mm |
| Diameter centerpiece | 35 mm |

## Material Rekomendasi

| Bagian | Material | Finishing |
|---|---|---|
| Body | Aluminium 6061-T6 | Anodized matte (warna tembaga) |
| Tulang kipas | Akrilik susu 3 mm | Laser cut |
| Centerpiece | Batu giok sintetis | Poles halus |
| Tombol cap | Resin / akrilik | Laser engrave motif 祥云 |

## File CAD

Letakkan file di folder ini:
- `fanora_body.stl`
- `fanora_fan_bones.dxf`
- `fanora_centerpiece.step`

## Tips Printing (FDM)

- Layer height: **0.16 mm**
- Infill: **20 %** (gyroid)
- Supports: **Ya** pada overhang busur
- Filament: PLA+ warna *bamboo* (opsional: PETG untuk kelembaban tinggi)
